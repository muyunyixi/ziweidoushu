# 紫微斗数 · 一生寥落动幽情

基于倪海厦《天纪》三合派体系与《紫微斗数全书》《紫微斗数全集》《骨髓赋》古典定式构建的**纯本地规则紫微斗数排盘与推演系统**（移动端优先响应式设计）。

## 核心功能模块

1. **单人紫微排盘（`/chart`）**
   - **排盘核心引擎**：支持真太阳时经度与均时差校正、1986–1991 中国夏令时判定、晚子时换日、四种闰月口径、十四主星与辅煞神煞安星、星曜七档亮度。
   - **本命 / 大限 / 流年切换**：即时叠加十年大限四化与流年四化飞星，点击任意宫位高亮三方四正连线。
   - **十三维与十二宫规则详批**：内置纯本地算法与古籍规则推演引擎，涵盖命格、性格、感情、事业、财运、健康（含天纪子午流注与地支脏腑对应）、福德、田宅、迁移、人际、兄弟、子女、父母十三维详批，以及十二宫即点即看、星曜详解弹窗、经典格局识别与高清命盘分享长图生成。
2. **双人紫微合盘（`/heming`）**
   - 依倪海厦《天纪》「命宫 · 夫妻宫 · 福德宫」双宫联参法则与生年四化飞化互参（甲飞乙、乙飞甲），即时生成双方十二宫对照命盘与五步合盘详批报告（涵盖感情契合度、合伙创业、婚期配比、磨合点与财运互补）。
3. **古籍原典检索（`/library`）**
   - 内置《紫微斗数全书》《紫微斗数全集》《骨髓赋》公版原文、白话释义与倪师批注，支持关键词全文检索。
4. **十四主星百科（`/knowledge`）**
   - 覆盖 14 主星 × 13 宫位专题共 182 篇结构化详论（含一句话定调、核心论断、命盘依据、经典出处）。
5. **卷轴开场预览（`/preview`）**
   - 仿古宣纸卷轴展开动效预览。

## 本地运行与一键部署

```bash
# 安装依赖
npm install

# 启动本地开发服务（默认 http://localhost:3000）
npm run dev

# 类型检查与排盘回归测试
npm run typecheck
npm test

# 生产环境构建
npm run build
```

### 部署上线（Vercel 零配置部署）
将本仓库推送至 GitHub 后，在 Vercel 中导入该仓库，保持默认的 Next.js 框架配置直接点击 **Deploy** 即可完成上线（无需配置任何后端数据库或第三方 AI 密钥）。
